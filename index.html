NOTES 01 — HARVEST & PARSE
1.1  Every Signal carries source_uri, fetched_at, adapter_name, adapter_version, run_id. Provenance is stamped at harvest; it cannot be reconstructed later.
1.2  An adapter that raises returns AdapterHealth.FAILED for the run. It does not return []. Empty and broken are different facts.
1.3  Parse failures logged per-record with raw payload hash. Adapters are read-only against the world.
FAIL: yield drop >30% vs 7-day median → DEGRADED · unreachable → 3× backoff then FAILED · ≥2 FAILED → exit 1 · all FAILED → exit 2, publish nothing.
VERIFY: fixture reproduces 12/12/10/10 · non-null source_uri + adapter_version · network kill yields FAILED not [].
NOTES 02 — GATE SCORING
2.1  Pure function of (ParsedSignal, calibration). No clock reads, no hash(), no network. Same inputs → same output on replay.
2.2  All four sub-scores persisted alongside the composite. Storing only the composite makes every future recalibration a guess.
2.3  A HOLD row is durable and re-enterable. Promotion to PASS is a new row with supersedes_id.
FAIL: gate exception → UNKNOWN not 0.0 · empty novelty corpus → require ≥5 prior PASS · stale clock inverts decay → assert fetched_at ≤ now · calibration edit without replay.
VERIFY: same fixture in two processes → byte-identical GateResults · replay harness reproduces bands on 3,076-record backfill.
NOTES 03 — PERSISTENCE
3.1  JSONL opened "a" only. A "w" on a canonical store is a Critical incident.
3.2  Mirror is never the source for any recalculation. Rebuild from JSONL or do not rebuild.
3.3  count(JSONL) == count(SQLite) asserted at end of every cycle. PG index on (node_id, gate_status, published_at DESC); gate scores stored flat and as jsonb.
FAIL: mirror drift → replay from offset · partial line → truncate to last complete, replay tail · duplicate run_id → refuse write, never delete · migration out of order → halt.
VERIFY: kill -9 mid-cycle leaves JSONL parseable and mirror repairable · UPDATE on political_signals refused by RULE.
NOTES 04 — THREAT INDEX ▲ OPEN
4.1  DOMAIN_WEIGHTS and ALPHA_OVERRIDE are placeholders pending backfill replay. Until calibrated the index must not drive an external alert or a published headline. PROVISIONAL badge on SWITCHBOARD only.
4.2  The dispatcher delivers. It does not compute, re-score, or re-band. Ever.
4.3  Every number in generated prose is validated against the source IndexRecord post-generation. Mismatch fails the run and falls back to the deterministic template. The LLM never authors a figure.
4.4  Cooldown state persists across restarts. Band escalation resets cooldown; de-escalation does not fire.
