    How to check this yourself

    Every statement on this site was recorded, with the Legislature's own data behind it, before it was published. The whole record is sealed with the publisher's digital signature. If anyone changes, adds, removes or reorders a single line afterward, the check below fails.

    1. Where the facts come from. Each bill's official action history, from the Oregon Legislature's public data service ({{ROWS}} recorded steps). The data file's fingerprint is {{CACHE_SHA}}….
    2. How each history was checked. Every step was replayed against Oregon's chamber procedure. A move that isn't allowed, or text the checker doesn't understand, stops the replay. That bill is then marked Not verified instead of guessed at. Not verified this session: {{UNVERIFIED}}.
    3. The publication gate. A bill's page is published only if every sentence on it points to official records sealed alongside it. Withheld by the gate: {{WITHHELD}}.
    4. Check it on your own computer. No internet or special software needed, just Python. Download the record, verify.py, anchor.json and the gate's rules, then run: 
      unzip chain.zip
python3 verify.py chain --pubkey {{PUBKEY}} --anchor anchor.json --policy civica.publish_card=civica_publish_card_policy.py
      A result of exit 0 means nothing was changed after it was recorded. Copy the public key from the publisher's key page, not from this page: a copied or fake version of this site can show any key it likes, but it can't produce a seal that passes with the real one. Key id {{KEY_ID}}, record ends at entry {{ANCHOR_SEQ}} ({{ANCHOR_H}}).

    What this does and doesn't prove

    It proves that what you see here matches what was recorded from the Legislature's public data, and that nothing was changed afterward. It does not prove the Legislature's own data is error-free. When we have found errors, we reported them. This site is about the public record of laws, including the laws about elections. It is not part of how ballots are cast or counted; that is run by county elections offices and the Oregon Secretary of State.
